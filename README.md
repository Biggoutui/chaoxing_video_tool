# 超星视频播放助手

一个超星学习通网页端视频播放辅助工具，基于 Python、Playwright 和 Google Chrome，旨在减少看视频时反复点击播放、处理弹题和切换章节的操作。

## 为什么做这个工具

超星学习通网页端部分课程视频无法顺畅连续播放，这是我们希望解决的问题：一段视频结束后需要手动切换，播放过程中也可能被弹题或暂停打断。如果每隔一段时间就要回到页面点击一次，连续观看课程会变得很不方便。

我们因此把重复的浏览器操作交给脚本：在已适配的页面中启动和恢复播放，尝试处理视频弹题，并在视频自然结束、对应任务点确认完成后切换到下一章节。我们的目标是让正常播放过程尽量连续，减少频繁点击和持续看守。

## 它能帮你完成什么

| 场景 | 当前脚本的处理方式 |
| --- | --- |
| 播放器暂停 | 在没有待处理弹题等阻碍时，尝试点击播放并恢复观看 |
| 同一章节有多个视频 | 依次处理可识别的视频播放器，也会等待延迟加载的视频 |
| 视频结束，需要切换章节 | 确认视频自然结束且对应任务点完成后，按课程目录切换 |
| 播放过程中弹出已适配的选择题 | 在可处理的条件下有限尝试选项，确认通过后继续学习 |
| 关闭后重新启动 | 尝试从身份匹配的最近章节继续，视频内时间位置由平台保存 |
| 课后习题、章节测验或考试 | 不进行自动作答或提交，需要用户自行完成 |

## 自动化范围与已知局限

本工具专注于视频播放流程。**播放器内弹题与课后习题属于不同范围：脚本会尝试处理前者，不会自动完成后者，也不能替代完整的课程学习与考核。**

弹题处理采用有限选项尝试，没有接入题库或 AI。判断题和单选题依次尝试选项；多选题仅处理总组合数不超过 31 的情况，超过上限会请求人工处理。能否继续取决于页面结构、反馈和重试条件，不保证每道弹题都能自动通过。

在已适配、登录有效且网络正常的情况下，可以减少中途手动操作；**当前版本不能保证完全无人监管**。首次登录或遇到验证码、真人验证时，仍可能需要人工处理；未知题型或多题弹窗、计分或限次提示，以及网络异常或任务点未确认等情况，也仍可能需要人工处理。暂停提示出现后，在浏览器处理问题，再回日志窗口按回车继续。

本项目与超星官方无关联。当前真实网站验证范围有限，不同学校、课程及页面更新可能影响兼容性。简明项目介绍见 [项目说明](项目说明.md)。

## 功能和边界

- 正常速度播放，暂停时尝试恢复；支持多视频卡片、目录切换和最近章节续播。
- 专用浏览器配置保存登录状态；首次登录、验证码和真人验证由用户手动完成。
- 只操作视频卡片和播放器内弹题，不提交章节测验，不倍速、不拖进度、不修改时长、不伪造学习记录。
- 视频弹题使用**有限选项尝试**，没有题库或 AI 答题：判断/单选依次尝试，多选最多尝试 31 个非空组合。出现计分或次数限制提示、未知结构、多道题或非选择题时交人工处理。
- 识别到的标准选择题弹窗需有明确错误反馈及重试提示才继续尝试；已适配的超星 `.ans-videoquiz` 则依据答对数量、弹窗和控件状态判断。这不是平台允许重试的保证，应自行确认课程要求。

## 环境

首版验证环境：**Windows、Python 3.10.16、Playwright 1.64.1、系统安装的 Google Chrome**。代码要求 Python 3.10 或更新版本；其他 Python 版本和 macOS/Linux 尚未完成验证，`.cmd` 入口仅适用于 Windows。

运行时使用系统 Chrome，不需要另外下载 Playwright Chromium。请先安装 Google Chrome，并保证电脑不会在运行中休眠。

## 安装

下载仓库 ZIP 并解压，或克隆仓库。在项目目录打开 PowerShell，依次执行：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config.example.json config.json
notepad config.json
```

如果安装的是其他 Python 3.10+ 版本，将第一行的 `py -3.10` 换成对应解释器。已存在 `config.json` 时跳过复制步骤，避免覆盖自己的配置。命令直接使用虚拟环境解释器，无需激活环境或更改 PowerShell 执行策略。

在 `config.json` 的 `url` 中填写本人课程的**完整 HTTPS studentstudy 学习页地址**；保留其它参数，不要填登录页或课程列表页。默认配置：

```json
{
  "url": "",
  "stall_timeout": 180
}
```

`stall_timeout` 是播放器停滞后请求人工处理的等待秒数，必须是大于 0 的有限数字。课程链接可能含身份或访问参数，请只保存在本地，不要贴到 Issue 或公开代码中。

## 使用

1. 双击 `start.cmd`，在新开的专用浏览器中手动登录。
2. 保持浏览器和日志窗口打开。需要人工处理时，在浏览器完成操作，再回日志窗口按回车继续。
3. 停止时在日志窗口按 `Ctrl+C`；下次启动会尝试从最近章节继续，视频内的播放位置由平台保存。

不要同时运行两份工具；同一账号在其他浏览器中的视频建议暂停。可以最小化日志窗口，不要直接关闭它来隐藏窗口。

三个启动入口优先使用项目 `.venv`，没有 `.venv` 时使用当前环境的 `python`。也可以直接调用 Python：

```powershell
.\.venv\Scripts\python.exe video_tool.py --help
.\.venv\Scripts\python.exe video_tool.py --once
.\.venv\Scripts\python.exe video_tool.py --login
```

| 参数或入口 | 用途 |
| --- | --- |
| `start.cmd` | 使用本地配置和匹配的历史进度启动 |
| `--url "完整学习页地址"` | 本次从指定地址开始，忽略历史进度；不要求存在配置文件 |
| `--once` | 只处理起始章节的视频 |
| `--login` / `login.cmd` | 仅登录并保存会话，不播放；完成后关闭工具浏览器 |
| `--inspect` / `inspect.cmd` | 登录后主动保存一次原始诊断，按回车关闭浏览器 |
| `--diagnostics` | 在异常或人工暂停时保存原始截图及 HTML，默认关闭 |

三个 `.cmd` 均可继续传入参数，例如 `start.cmd --once`、`login.cmd --url "完整学习页地址"`。`--login` 和 `--inspect` 应分别使用；同时指定时优先执行仅登录模式。

临时指定课程且不将地址直接写入命令历史的方式：

```powershell
$courseUrl = Read-Host '粘贴完整学习页地址'
.\.venv\Scripts\python.exe video_tool.py --url "$courseUrl" --once
```

地址优先级：显式 `--url` → 与配置身份匹配的历史地址 → 配置地址。只有课程、班级和用户关联标识齐全且一致时才自动续播；无法确认身份时，从配置地址开始。损坏的进度会被忽略并提示，损坏的配置需要修正后重试。

## 隐私和本地文件

| 文件或目录 | 本地用途 |
| --- | --- |
| `config.json` | 本人的课程地址和等待设置 |
| `progress.json` | 最近章节及完整学习地址 |
| `browser_profile/` | 专用浏览器 Cookies、登录会话、历史和缓存 |
| `logs/run.log` | UTF-8 运行日志；新日志会遮去 URL 查询值及本机 Windows 路径 |
| `diagnostics/` | 主动启用后的原始页面截图、视频区域 HTML、任务状态和原因 |
| `quiz_selectors.json` | 可选弹题选择器适配，默认为空对象 |

默认不保存截图或 HTML，正常切换章节及弹题提交也不采集。`--inspect` 和 `--diagnostics` 的产物**可能包含姓名和头像，也可能包含课程内容与带访问参数的资源地址**，不保证自动脱敏。旧日志也不会被追溯清洗。即使新日志已遮去链接参数，分享前仍应人工检查。

以上个人配置、运行数据及根目录截图已加入 `.gitignore`。不要将整个本地目录压缩后上传，不要发送 `browser_profile/`、个人配置或原始诊断包。

退出账号可在工具浏览器中操作。若需清除本机保存的会话，先停止工具并关闭其浏览器，再删除本地 `browser_profile/`；下次会新建并要求登录。切换账号时建议同时删除 `progress.json`，保留或重新填写自己的配置。

## 常见问题

- **找不到 Python / Playwright**：按安装步骤创建 `.venv` 并安装依赖；也可在已安装依赖的环境中直接运行 Python 命令。
- **无法启动 Chrome**：确认系统已安装 Google Chrome、没有另一个工具占用同一浏览器配置，先关闭工具浏览器再重试。不要在浏览器运行时删除配置目录。
- **配置报错**：检查 JSON 双引号、逗号和编码，地址应为完整 HTTPS 学习页；超时必须是正数。
- **登录失效或出现验证**：在专用浏览器中手动完成，必要时运行 `login.cmd` 后重新启动。等待登录超过约 15 分钟会退出。
- **播放器停滞或页面变化**：先根据日志人工处理，必要时主动开启诊断。本地 `quiz_selectors.json` 允许调试已知结构；无适配时不要盲目增加自动点击。
- **网页显示完成但没有切章**：工具同时要求视频自然结束和对应视频任务点确认完成；结束后最多再等待约一分钟，不会仅凭整章绿勾跳过视频。
- **换课后未续播**：身份信息不齐全或与历史不匹配时会从配置地址开始，可用 `--url` 明确选择起点。

## 测试和验证范围

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_video_tool test_release test_browser
```

测试使用本地模拟网页和临时数据目录，并使用独立 headless Chrome，不连接真实课程、不使用本机登录资料。`fixtures/chaoxing_quiz.html` 使用自编题干及播放器弹题 DOM 结构；模拟提交反馈不代表真实网站结果。

已有真实网站验证限于手动登录、会话复用、一类判断题弹窗、视频自然结束及目录切章。真实单选、多选和不同学校/课程页面尚未充分验证。详细范围见 [验证记录](验证记录.md)。GitHub Actions 会运行 Windows 离线测试；不会自动登录真实账号。
